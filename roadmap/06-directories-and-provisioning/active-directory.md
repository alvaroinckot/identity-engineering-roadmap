# Active Directory

**TL;DR:** Active Directory Domain Services is Microsoft's directory service, a hierarchical
store of objects such as user accounts, computers, and printers. Its schema defines object
classes and attributes, and its query and index mechanisms let applications find them. It gives
an organization a shared set of network accounts, with sign-in authentication, access control
to directory objects, and policy-based administration integrated into the directory. Every
domain controller participates in replication and contains a complete copy of its domain's
directory information, so changes can be distributed across the network.

A directory service, "the methods for storing directory data and making this data available
to network users and administrators", with sign-in authentication, access control to
directory objects and policy-based administration integrated into it (AD DS overview).
