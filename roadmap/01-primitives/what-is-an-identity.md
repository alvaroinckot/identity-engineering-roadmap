# What is an identity?

**TL;DR:** An identity is the set of attributes that describes one subject, a person or a piece
of software, within one context. An identifier is a single value, such as a username or a user
ID, that a system uses to refer to that identity. One identity commonly has several
identifiers. NIST's glossary reserves identifier for a value that is never reassigned within
its context, so use a stable, non-reassigned value for a persistent account reference. The rest
of the map uses this vocabulary: the subject is the party the attributes describe, a principal
is the identity a user claims when accessing a system, and a claimant is a subject proving that
claim.

Subject, principal, claimant; identifier vs. identity. An identity is "an attribute or set
of attributes that uniquely describes a subject within a given context" (SP 800-63-4, App.
B); a username is just one identifier for it.
